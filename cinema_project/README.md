# Система бронирования билетов в кинотеатре (Cinema Backend)

## О проекте
Backend-сервис для кинотеатра. Позволяет управлять фильмами, залами, сеансами и продажей билетов. Проект подготовлен как база для изучения масштабирования баз данных (PostgreSQL).

## Запуск
```bash
docker compose up -d --build
